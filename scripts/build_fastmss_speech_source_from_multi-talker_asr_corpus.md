# Build FastMSS Speech Source from Multi-Talker ASR Corpus (STM + WAV)

## Problem

Multi-talker ASR datasets (e.g., AMI, LibriCSS, AliMeeting, MLC) provide:
- Full session audio (multi-speaker mixed, `.wav`)
- STM files (speaker-labeled segments with timestamps, `.stm`)

FastMSS requires **single-speaker MonoCut** sources with word-level alignments. This document designs a Stage A' script that extracts single-speaker audio segments from multi-talker corpora and prepares them for the existing FastMSS data pipeline (Stage B → C → D).

## Pipeline Position

The script sits as **Stage A'** — between an already-annotated multi-talker corpus and Stage B (forced alignment).

```
Multi-Talker ASR Corpus             (session_01.wav + session_01.stm)
  │
  ▼
[Stage A'] ──▶ single-speaker WAV + per-segment STM    ← THIS SCRIPT
  │              wav/session_01_spkA_0000.wav
  │              stm/session_01_spkA_0000.stm
  │              wav2stm.scp, wav2spk.scp, meta.tsv
  │
  ▼
[Stage B] ──▶ word-level alignment JSON               (run_alignment.py)
  │
  ▼
[Stage C] ──▶ Lhotse CutSet MonoCut                   (alignment_to_lhotse.py)
  │
  ▼
[Stage D] ──▶ FastMSS multi-speaker simulation         (sim.py)
```

Word-level alignments are generated by Stage B (forced alignment). Stage A' only handles the extraction of single-speaker segments from multi-talker recordings.

## Input Format

### Audio
```
{corpus_root}/audio/
  session_01.wav       # single-channel or multi-channel, 16 kHz
  session_02.wav
  ...
```

### STM
NIST STM format — 7 fields, space-separated, with `<NA>` as placeholders:
```
<filename> <channel> <begin> <end> <speaker_id> <NA> <text>
```
Example (`session_01.stm`):
```
session_01 1 0.00  3.45  speaker_A  <NA>  hello world
session_01 1 3.60  5.20  speaker_B  <NA>  how are you
session_01 1 5.30  8.10  speaker_A  <NA>  i am fine
session_01 1 8.25  11.50 speaker_B  <NA>  good thanks
session_01 1 12.00 15.30 speaker_A  <NA>  let us begin the meeting
```

## Core Algorithm

### Step 1: Parse STM

Read the STM file, extract per-speaker segments:

```python
@dataclass
class STMSegment:
    filename: str    # session basename
    channel: int
    begin: float
    end: float
    speaker_id: str
    text: str
```

Skip lines where `end <= begin`. Warn on parse failures. Skip comment lines (`;` prefix).

### Step 2: Group & Merge Per-Speaker Segments

For each speaker, merge temporally nearby STM entries into longer contiguous segments using a configurable gap threshold (`--merge-gap`, default 0.5s):

```
Speaker A: [0.0, 3.45] ─gap(1.85s)─ [5.3, 8.1] ─gap(3.9s)─ [12.0, 15.3]
              │                         │                        │
              └─ separate (gap>0.5)     └─ separate (gap>0.5)   └─ separate
              │                         │                        │
              ▼                         ▼                        ▼
         seg_0000 (dur=3.45)       seg_0001 (dur=2.80)     seg_0002 (dur=3.30)
```

**Merge strategy:**
1. Sort STM entries for a speaker by `begin` time
2. Iterate: if `next.begin - current.end <= merge_gap`, extend `current.end = max(current.end, next.end)` and concatenate text
3. Each merged group produces one output segment

**Rationale:** The default gap of 0.5s distinguishes within-sentence pauses from inter-utterance gaps. This avoids over-fragmentation (hundreds of 1s files) and over-merging (exceeding the forced aligner's 300s limit).

### Step 3: Split Long Segments

If a merged segment exceeds `--max-duration` (default 30s), recursively split it at the largest internal gap:

```
Merged: [A1][A2]────big gap────[A3][A4][A5]──small gap──[A6]
                                    │
                                    ▼ split here
                      seg_N (dur<30)    seg_N+1 (dur<30)
```

This produces segments that are both natural (gap-based boundaries) and within the duration limit.

### Step 4: Audio Extraction

For each merged speaker segment `[begin, end]`, extract audio from the full session recording:

```python
import soundfile as sf

session_audio, sr = sf.read(session_wav_path)
assert sr == 16000

start_sample = max(0, int((begin - pad) * sr))
end_sample = min(len(audio), int((end + pad) * sr))
segment_audio = session_audio[start_sample:end_sample]
```

Add a margin (`--pad`, default 0.05s) on each side to avoid clipping onset transients.

Write extracted audio:
```
{output_dir}/wav/{session_id}_{speaker_id}_{seg_index:04d}.wav
```

**Utt ID convention:** `{session_id}_{speaker_id}_{seg_index:04d}` — preserves traceability back to source session and speaker, avoids collisions across sessions.

### Step 5: Write Per-Segment STM

For each extracted segment, write a single-speaker STM file for Stage B forced alignment input:

```
{output_dir}/stm/{session_id}_{speaker_id}_{seg_index:04d}.stm
```

Content (adjust times relative to segment start, single speaker):
```
session_01_spkA_0000 1 spk0 0.00 {segment_duration} <NA> <NA> hello world i am fine
```

The text concatenates all STM entry texts within the merged segment. Speaker is set to `spk0` (single-speaker segment).

### Step 6: Speaker & STM Mapping

Produce two mapping files:

**`wav2spk.scp`** — speaker mapping for Stage C (`alignment_to_lhotse.py --spk-scp`):
```
<wav_path> <speaker_id>
```
The speaker_id is namespaced: `{session_id}_{original_speaker_id}` to avoid cross-session speaker ID conflicts.

**`wav2stm.scp`** — STM mapping for Stage B (forced alignment):
```
<wav_path> <stm_path>
```

### Step 7: Split into train/dev/test

Split by **session** (not segment) to prevent data leakage — all segments from the same original session go to the same split:

```python
# Group segments by session_id
# Shuffle session list with fixed seed (--seed)
# Assign sessions to train/dev/test by ratio
```

### Step 8: Write Metadata

`meta.tsv` with per-segment statistics:
```
utt_id<TAB>session_id<TAB>speaker_id<TAB>begin<TAB>end<TAB>duration<TAB>num_stm_entries<TAB>text<TAB>split
```

## Key Design Decisions

### 1. Merge Gap vs. Raw STM Entries

| Approach | Pros | Cons |
|---|---|---|
| Raw STM entries | Exact annotation boundaries | Many fragments < 2s; STM boundaries may cut mid-sentence |
| Merged with gap ≤ 0.5s | Natural utterance boundaries; better alignment context; fewer files | Can produce long segments; need `--max-duration` cap |

**Decision:** Merge with `--merge-gap 0.5` + `--max-duration 30` cap.

### 2. Handling Overlapping Speech

STM files may contain overlapping segments (two speakers talking simultaneously):

| Option | Behavior | Use Case |
|---|---|---|
| **Keep overlaps** (default) | Extract audio as-is from mixed region; both speakers include crosstalk | Adds realistic acoustic diversity |
| Trim overlaps | Remove regions where another speaker is active | Maximizes clean single-speaker audio |

**Decision:** Keep overlaps. FastMSS simulation introduces its own controlled overlaps; natural crosstalk adds diversity.

### 3. Speaker ID Namespacing

Multi-talker STM files have speaker labels that may conflict across sessions (e.g., both `session_01` and `session_02` have `speaker_A`).

**Decision:** Namespace speaker_id as `{session_id}_{speaker_id}`. FastMSS builds `spk2cuts` from speaker IDs — without namespacing, different people across sessions with the same label would share utterances, limiting diversity.

### 4. Maximum Duration Cap

Forced aligners (e.g., Qwen3-ForcedAligner) typically have a maximum input duration (~300s). Long continuous utterances waste GPU memory and degrade alignment quality.

**Decision:** Cap at 30s with recursive gap-based splitting. This is well within the aligner's limit while keeping segments long enough for meaningful pause-splitting downstream.

### 5. Per-Segment STM Output

Stage B forced alignment requires per-utterance STM files. Each extracted segment gets its own STM with the concatenated text and times adjusted relative to the segment start.

**Decision:** Generate `stm/` directory alongside `wav/`, with `wav2stm.scp` for Stage B input.

## Design Analysis: WAV Extraction vs. Offset-Based Index

### The NeMo Manifest Format

The NeMo training manifest (`nemo_manifest.jsonl`) uses an offset-based reference style:
```json
{"audio_filepath": "/data/session_01.wav", "offset": 5.3, "duration": 2.8, "num_speakers": 1, "rttm_filepath": "..."}
```

This is space-efficient because it does NOT extract audio — it only records where each segment lives in the source file. The source WAV is the single source of truth; all segments point into it with `offset` + `duration`.

### Why This Pipeline Currently Extracts WAVs

The constraint is **Stage B forced alignment**. `run_alignment.py:167` passes file paths directly to Qwen3Aligner:

```python
raw = self._model.align(audio=audio_paths, text=texts, language=resolved_langs)
```

The aligner internally calls `soundfile.read(audio_path)` — it needs a self-contained WAV file, not an offset reference into a larger session recording.

### Downstream Chain Analysis

| Stage | Needs actual WAV file? | Why |
|---|---|---|
| B (forced alignment) | **Yes** | Qwen3Aligner reads WAV by path, no offset API |
| C (alignment → CutSet) | **Yes** | `Recording.from_file(wav_path)` records duration/sr from the file |
| D (FastMSS simulation) | **Yes** | `cut.load_audio()` reads from Recording's file path |

All three stages require individual WAV files. The NeMo manifest format works for training data because the data loader reads audio with offset-aware slicing — but that capability doesn't exist in the forced aligner or FastMSS source loading.

### Space Estimate

For a typical multi-talker ASR corpus (100h source audio, 10 speakers/session average):

| Parameter | Value |
|---|---|
| Total speaker-hours | 100h |
| Avg segment duration (after merge+split) | 8s |
| Total segments | ~45,000 |
| Per-segment WAV size (16kHz mono) | ~256 KB |
| **Total extracted WAVs** | **~11 GB** |

11 GB per 100h of source audio is manageable but not negligible. For larger corpora (1000h+), this becomes 100GB+.

### Future Alternative: Offset-Based Index + Temp Extraction

A space-optimized variant would work as follows:

```
Stage A' (this script)  →  segments.jsonl  (offset-based index, NO WAV extraction)
                            [{audio: session_01.wav, offset: 5.3, dur: 2.8, text: "..."}]

Stage B' (new wrapper)   →  for each segment:
                            1. sf.read(session_wav, start=offset*sr, stop=(offset+dur)*sr)
                            2. write temp WAV
                            3. run alignment
                            4. delete temp WAV

Stage C  (alignment → CutSet)  →  create Recording pointing to session WAV,
                                  MonoCut with start=offset
```

This eliminates permanent WAV storage but requires:
1. **Stage B enhancement**: A wrapper script (or a `--segments` mode in `run_alignment.py`) that accepts offset-based index, extracts temp audio, and cleans up
2. **Stage C enhancement**: `alignment_to_lhotse.py` optionally accepts an offset manifest to build referencing CutSets (Recording → session WAV, MonoCut.start = offset)

The Lhotse `MonoCut` API natively supports this: `MonoCut(start=offset, duration=dur, recording=session_rec)` where `session_rec = Recording.from_file(session_wav)`. During simulation, `cut.load_audio()` correctly slices `[offset*sr : (offset+duration)*sr]`.

### Recommendation

**Current design: Extract WAVs.** This is the simpler path, fully compatible with existing tools, and the space cost is acceptable for all but the largest corpora.

**For large corpora (>500h source)**: Consider implementing Path B as a parallel mode (`--mode index`). The Stage A' core logic (STM parsing, merging, splitting) is the same; only the output serialization differs. A `--mode index` flag would:
- Skip WAV extraction
- Write a `segments.jsonl` with offset references + text
- Write a `wav2spk.scp` for later speaker mapping

This defers the actual WAV I/O to Stage B' (temp extraction wrapper). The downstream tool modifications are localized and well-bounded.

## Edge Cases & Notes

1. **STM with session filename mismatch:** STM `filename` field may differ from the audio basename. Match STM ↔ WAV by basename of the input file (not the STM filename field). If unmatched, log warning and skip.

2. **Large session WAV files:** Loading a full 30-minute session into memory may be expensive. Use `soundfile` (supports memory-mapped I/O) or consider extracting with `ffmpeg`/`sox` subprocess for very large sessions.

3. **Sample rate:** All source audio should be 16 kHz. Add a `--check-sample-rate` flag that validates and warns (resampling can be added later if needed).

4. **Empty extracts:** If after filtering by `--min-duration` a speaker has zero valid segments, log a warning but don't fail — other speakers in the session may still produce valid output.

5. **Per-segment STM speaker label:** Output STM files use `spk0` as the speaker label since each extracted segment is single-speaker. The real speaker identity is encoded in the filename and `wav2spk.scp`.

6. **Session-level split guarantee:** All segments from the same original session go to the same train/dev/test split. This prevents the same recording environment from inflating cross-split generalization scores.

7. **Speaker count diversity:** Multi-talker corpora with many unique speakers per session provide richer source diversity for FastMSS's `spk2cuts` mapping. Corpora where 2–3 speakers dominate all sessions will reduce simulated meeting diversity.

8. **Text for Stage B alignment:** The concatenated STM text in each per-segment STM file is used as the reference transcription for forced alignment. Verify that the text matches the extracted audio content; STM annotation errors will propagate to alignment errors.

## Implementation Outline

```python
#!/usr/bin/env python3
"""
Build single-speaker audio + STM segments from multi-talker ASR corpus (audio + STM).

Input:  {audio_dir}/*.wav  +  {stm_dir}/*.stm
Output: {output_dir}/wav/*.wav, stm/*.stm, wav2stm.scp, wav2spk.scp, meta.tsv
"""

import argparse
import random
from collections import defaultdict
from dataclasses import dataclass, field
from pathlib import Path
from typing import Dict, List

import numpy as np
import soundfile as sf
from tqdm import tqdm


@dataclass
class STMSegment:
    filename: str
    channel: int
    begin: float
    end: float
    speaker_id: str
    text: str


@dataclass
class MergedSegment:
    session_id: str
    speaker_id: str
    seg_index: int
    begin: float
    end: float
    text: str
    stm_entries: List[STMSegment] = field(default_factory=list)


def parse_stm(stm_path: Path) -> List[STMSegment]:
    """Parse NIST STM file."""
    segments = []
    with open(stm_path) as f:
        for line in f:
            line = line.strip()
            if not line or line.startswith(";"):
                continue
            parts = line.split()
            if len(parts) < 7:
                continue
            try:
                seg = STMSegment(
                    filename=parts[0],
                    channel=int(parts[1]),
                    begin=float(parts[2]),
                    end=float(parts[3]),
                    speaker_id=parts[4],
                    text=" ".join(parts[6:]) if len(parts) > 6 else "",
                )
                if seg.end > seg.begin:
                    segments.append(seg)
            except (ValueError, IndexError):
                continue
    return segments


def merge_segments(
    segments: List[STMSegment],
    merge_gap: float,
    max_duration: float,
    min_duration: float,
    session_id: str,
) -> List[MergedSegment]:
    """Merge nearby same-speaker STM entries; split long groups at gaps."""
    # Filter by min_duration
    segments = [s for s in segments if s.end - s.begin >= min_duration]

    # Group by speaker
    by_speaker = defaultdict(list)
    for seg in segments:
        by_speaker[seg.speaker_id].append(seg)

    merged = []
    for speaker_id, segs in by_speaker.items():
        segs.sort(key=lambda s: s.begin)

        # Merge adjacent segments within merge_gap
        groups = []
        current_group = [segs[0]]
        for seg in segs[1:]:
            gap = seg.begin - current_group[-1].end
            if gap <= merge_gap:
                current_group.append(seg)
            else:
                groups.append(current_group)
                current_group = [seg]
        groups.append(current_group)

        # Split groups exceeding max_duration at largest internal gap
        final_groups = []
        for group in groups:
            final_groups.extend(_split_long_group(group, max_duration))

        for idx, group in enumerate(final_groups):
            begin = group[0].begin
            end = max(s.end for s in group)
            text = " ".join(s.text for s in group if s.text)
            merged.append(MergedSegment(
                session_id=session_id,
                speaker_id=speaker_id,
                seg_index=idx,
                begin=begin, end=end, text=text,
                stm_entries=group,
            ))

    return merged


def _split_long_group(
    group: List[STMSegment], max_duration: float
) -> List[List[STMSegment]]:
    """Recursively split a group if its total duration exceeds max_duration."""
    total_dur = max(s.end for s in group) - group[0].begin
    if total_dur <= max_duration or len(group) <= 1:
        return [group]

    max_gap, split_idx = 0, 0
    for i in range(len(group) - 1):
        gap = group[i + 1].begin - group[i].end
        if gap > max_gap:
            max_gap = gap
            split_idx = i

    left = _split_long_group(group[:split_idx + 1], max_duration)
    right = _split_long_group(group[split_idx + 1:], max_duration)
    return left + right


def extract_audio(
    session_wav: Path, begin: float, end: float,
    pad: float, sr: int = 16000,
) -> np.ndarray:
    """Extract a time range from a session WAV."""
    audio, file_sr = sf.read(session_wav)
    assert file_sr == sr, f"Sample rate mismatch: {file_sr} != {sr}"
    start_sample = max(0, int((begin - pad) * sr))
    end_sample = min(len(audio), int((end + pad) * sr))
    return audio[start_sample:end_sample]


def write_stm(seg: MergedSegment, stm_path: Path, pad: float):
    """Write per-segment STM for Stage B forced alignment."""
    utt_id = f"{seg.session_id}_{seg.speaker_id}_{seg.seg_index:04d}"
    duration = seg.end - seg.begin + 2 * pad
    with open(stm_path, "w") as f:
        f.write(f"{utt_id} 1 spk0 0.00 {duration:.2f} <NA> <NA> {seg.text}\n")


def split_by_session(
    merged_segments: List[MergedSegment],
    split_names: List[str],
    ratios: Dict[str, float],
    seed: int,
) -> Dict[str, List[MergedSegment]]:
    """Split by session ID to prevent data leakage."""
    by_session = defaultdict(list)
    for seg in merged_segments:
        by_session[seg.session_id].append(seg)

    session_ids = list(by_session.keys())
    rng = random.Random(seed)
    rng.shuffle(session_ids)

    n = len(session_ids)
    splits = {}
    start = 0
    for i, name in enumerate(split_names):
        end = n if i == len(split_names) - 1 else start + int(n * ratios[name])
        splits[name] = [seg for sid in session_ids[start:end] for seg in by_session[sid]]
        start = end
    return splits


def main():
    # --- CLI parsing ---
    # --- Discovery: pair .stm + .wav by basename ---
    # --- For each session: ---
    #   1. Parse STM
    #   2. Merge segments per speaker
    #   3. For each merged segment:
    #      a. Extract audio → wav/{utt_id}.wav
    #      b. Write per-segment STM → stm/{utt_id}.stm
    #   4. Collect all segments
    # --- Split by session ---
    # --- Write wav2stm.scp, wav2spk.scp, meta.tsv ---
    # --- Report: total segments, total duration, speaker count ---
    pass


if __name__ == "__main__":
    main()
```
